# Dataset

`sample_hr_attrition.csv` is a **synthetic demonstration dataset** generated for this portfolio project. It does not represent real employees or a real organization.

For additional experimentation, you may use the IBM HR Analytics Attrition dataset only after checking its source and applicable terms. Keep private, confidential, or personally identifying employee data out of this public repository.

The target column used by default in the app is `Attrition` (Yes/No).
